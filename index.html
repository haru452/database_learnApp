アプリの「Topic」で、お題について話したときの点数です（100点満点）。

使い方
  1. お題をもらうNew Topic を押すと、お題が出ます。種類は試験（Exam）・日常（Daily）・仕事（Work）のどれかで、話す時間は Daily が 45 秒、ほかは 60 秒です。
    • Hint: 答えの組み立て方のヒント
    • Today's focus: 最近よくするミスの種類（採点でも重点的に見ます）
  2. 考える「Think」のカウントダウン中に答えを考えます。準備ができたら Start now ですぐ話し始められます（0 になると自動で始まります）。
  3. 話す英語で答えて、終わったら Finish（時間切れでも自動で終わります）。答えは録音されるので、話している途中に文字は出ません。
  4. 採点を待つGemini が録音を聞いて書き起こし、採点します（1 分ほどかかることがあります）。
    • 待っている間は Diary や Summary に移って大丈夫です。終わると通知が出て、タブが「Topic ●」になります。
    • 失敗したときは録音が残っているので Retry で送り直せます。
  5. 結果を見る点数（内容 40・構成 30・文法と語彙 30）、良かった点・直す点、直した文（Corrected）、自然な言い方（More natural）、次に使える表現が出ます。
  6. 直した文を読む質問の場所に、読む文（最大 3 文）が出ます。
    • Read aloud: 読んで Stop。言えた単語は緑、言えなかった単語は赤で、一致率（%）が出ます。
    • Pronunciation check: 読んで Stop。発音のアドバイスが出ます（点数は付きません）。
    • Next で次の文へ。全部読むと平均の一致率が記録されます。
  7. 記録を見るこのページで点数の推移と過去の結果、「よくあるミス」でミスの種類が見られます。カレンダーはお題をやった日が緑（2 種類で紫、3 つ全部で金）になり、お題だけの日も連続記録は途切れません。

考える時間や話している途中に別の画面へ移ると中断されます。考える時間の長さは Unity の Inspector の Think Seconds で変えられます。

項目ごとの点数

内容 40点 + 構成 30点 + 文法・語彙 30点 = 100点

アプリの「Repeat」で、聞いた英文を言い返したときの一致率です（言えた単語の割合）。

使い方
  1. 始めるStart を押すと、5 文の練習が始まります。前回言えなかった文、自分の添削文（日記・要約・お題）、Tatoeba の文が混ざって出ます。
  2. 聞く英文は見せずに読み上げます。Tatoeba の文は本物の人の声、自分の添削文は AI の声です。Again でもう一度、Slow でゆっくり（声の高さはそのまま）聞けます。
  3. 言い返すSpeak を押して同じ文を言い、Stop。聞き取れなかったときは 0% にせず、もう一度言えます。
  4. 確かめる英文が枠の中に出て、言えた単語は緑、抜けた単語は赤、一致率（%）が出ます。Try again で言い直し、Next で次の文へ。
  5. まとめ5 文が終わると平均が出ます。80% 未満の文は、次の練習で優先して出ます（このページの「苦手な文」）。
  6. シャドーイング上の Shadowing: On にすると、BBC Learning English「6 Minute English」の続いた 5 文で練習します。1 回目は聞くだけ（Skip で飛ばせます）、3・2・1 のあと 2 回目で声に重ねて話します。イヤホンを使ってください（付いていないと確認が出ます）。Slow: On でゆっくり。終わると My voice（自分の声）と Original（お手本）を聞き比べられます。Web には点数だけを保存し（英文と自分が言った内容は Discord にだけ送ります）、結果には「シャドー」の印が付きます。苦手な文には入りません。

練習の途中でほかのタブへ移ると中断します。文と録音は Tatoeba（tatoeba.org）のもの、シャドーイングの音声は BBC Learning English のものです（どちらも個人の学習用）。
